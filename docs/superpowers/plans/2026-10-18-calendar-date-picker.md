## Exact private shared contract (owned only by C1)

New private `packages/primitives/src/internal/form-validity.tsx` exports to internal consumers only:

```ts
interface FormValiditySource {
  baseline: Accessor<string>; // '' means no component-domain error
  revision: Accessor<number>; // increments on domain/value identity changes
}
interface FormValidityOwner {
  name: Accessor<string | undefined>; // resolved Form.Field/Control name before Slot merge
  form: Accessor<string | undefined>; // explicit Form.Control form association
  register(source: FormValiditySource): () => void;
  revalidate(): void;
}
function FormValidityProvider(props: { value: FormValidityOwner; children?: Element }): Element;
function useFormValidityOwner(): FormValidityOwner | undefined;
```

`Accessor` and native `Element` are existing `solid-js` types; `Scope` below is the existing type from `packages/primitives/src/internal/context.tsx`. No new type/runtime package is introduced.

Use native Solid context/owner cleanup, not a public context framework. One Form.Control owns one registered source and native input; a second live source is a configuration error. `register` returns cleanup. `revalidate` invalidates the previous generation and runs existing validate against the projected input and current baseline/revision. Async currency includes the registered revision in addition to existing value/version/ref checks. Baseline changes reactively invalidate/revalidate; clear/reset preserves the current baseline while clearing appropriate matcher results. Unregistered ordinary Form.Control remains unchanged. FileDrop revisions compare ordered File references, not fakepath; C3 increments for accepted date/constraint changes. No DOM normalization event is required for managed revalidation.

The owner exposes resolved name and explicit form before target props can mask them; registered children compare these getters with Root as well as checking incoming/target names. This private metadata preserves the wrapper/matcher key, not a new public Form API.
