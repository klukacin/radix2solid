Focused Chromium/Firefox/WebKit SSR/CSR coverage verifies the selected behavior and existing native boundaries. Legacy Firefox/WebKit coverage passed 38 cases with two intentional skips; the section-wide disposal case passed all six projects after correcting the gallery's existing mount boundary. Full CI and publication are separate, still-pending steps.

### Native SSR and ownership decisions

Position-set/default-mount Legends alone use the wrapper-owned HTML outlet. Ordinary chart children register payload/settings once using the existing chart initializer; no prewalk or second initialization engine is introduced. The shared Legend body runs under its original owner/context, with outlet disposal and store unregistering. Legacy no-position and supplied custom portals remain DOM-only. Position-based server coordinates use a zero measured box; final outside placement and plot reservation use browser measurement. Initial node identity and cleanup are explicit gate requirements, not inferred from source.

The initial claim covers server ticks, labels and Legend icons as well as outer containers. Their identities need not persist after apply-phase tick thinning/geometry updates or the native raw-seed-to-store transition. The frozen receipt retained all server nodes through the first measurements, then replaced87 tick texts,6 inner Legend icons and1 custom Pie label while preserving every outer SVG and Legend wrapper. The browser case keeps the full premeasurement claim and exact persistent-container/owner lifetime assertions separately.

The clip producer correction changes observable server defs order/clip geometry for numeric and automatic axes alike. It retains provider/ID generation, ordinary children and numeric tick geometry; tests compare semantic geometry and actual DOM ownership, not raw markup or hydration keys. Existing native-ID, tick-ladder, Cell, sync and panorama cases remain required.

The unselected comparison disposition is complete in `upstream.json`: #7525 theme, #7545 Tooltip comments/type and #7560 Legend type are pending; 21 dependency-only commits, three version-only commits, the unchanged skill moves, visual snapshots and two documentation-only source commits are not applicable. PR #3's CellReader, theme exports/files, unrelated Line id change and undefined-label auto-height shortcut are not imported. LICENSE, NOTICE, D3 graph and the imported source/archive identity are preserved.
